# 🎮 About The Game

**دورهمی (Dorehami)** یک بازی پارتی چندنفره محلی است که برای بازی کردن چند نفر روی یک دستگاه طراحی شده است.

بازیکنان می‌توانند در حالت‌های مختلف بازی با دوستان خود رقابت کنند، امتیاز بگیرند و لحظات سرگرم‌کننده‌ای بسازند.

این پروژه به عنوان یک نمونه کار برای نمایش مهارت‌های **Unity Game Development**، برنامه‌نویسی C#، طراحی سیستم‌های Gameplay و UI/UX توسعه داده شده است.
